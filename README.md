# Personal website portfolio

极简浅色个人站：简历、作品（平面 / 产品 / 空间）、中英切换、简历导出 PDF。静态 HTML/CSS/JS。

## 在线访问（开启 GitHub Pages 后）

`https://jjjjiris.github.io/Personal-website-portfolio-/`

## 本地预览

用浏览器打开 `index.html`，或在目录下执行 `python3 -m http.server 8080` 后访问 <http://localhost:8080>。

## Pages 设置

仓库 **Settings → Pages**：**Source** 选 **Deploy from a branch**，Branch 选 **main**、文件夹 **/ (root)**，保存即可（首启约 1～2 分钟生效）。
